
# Exercise 0.6: New note in Single Page App

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save

    Note right of browser: JavaScript prevents default form submission
    browser->>browser: Create note object with content and date

    browser->>server: POST /new_note_spa
    Note right of browser: Send note as JSON
    activate server
    server->>server: Save the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: JavaScript adds the new note to the DOM
    Note right of browser: Page is not reloaded
```
